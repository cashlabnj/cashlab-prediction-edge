## What this is

A transparent, auditable record of a prediction-market trading lane that exploits the
**favorite–longshot bias** on Kalshi's Exotics (parlay/combo) markets.

The core idea: these markets systematically **overprice the longshot (YES) side**, which makes
the **NO side systematically cheap**. The lane buys NO at the displayed bid using `post_only=true`
(maker orders). On Kalshi's `KXMVE*` series the fee type is `quadratic` with a **$0 maker fee**,
so a NO contract bought at 55¢ that settles NO ~71% of the time is roughly +14¢ of expected value
per contract, collected as a structural edge rather than a directional bet.

This is the *one* lane in a much larger system that survived full forward validation. The rest of
the system (market-making, LIP incentive quoting, strikeout props) is documented but ran into
either (a) capital constraints or (b) no-repeatable-edge findings, and is kept paper-only.

**The single hard bottleneck to scaling is capital.** `favorite-grind` is operator-approved for
live execution but is currently frozen at ~$3 Kalshi cash — live orders are placed and then
server-rejected until the account is funded. The edge is real; the runway is not.
